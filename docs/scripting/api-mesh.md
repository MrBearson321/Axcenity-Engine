# MeshPart and SurfaceAppearance

Imported models and their texture maps from Lua.

- **MeshPart** (Phase 17): `Instance.new("MeshPart")` works, with `Anchored`, `Position`, `Orientation`, `Size` and `MeshId` (a model's path in the project, such as `"assets/models/pyramid.gltf"`; `.gltf`, `.glb` and `.fbx` files work, and `#` after the file picks objects in it: `"assets/models/props.fbx#Bench"`), and fires `Touched` like a Part. Setting `MeshId` loads that model the first time it's drawn; a path outside the project is refused, and a model that can't be loaded is reported once and drawn as a grey box. It has no `Color` or `Material`: it uses the file's materials.
- **SurfaceAppearance** (Phase 21): `Instance.new("SurfaceAppearance")` inside a Part draws its maps on that part. Inside a MeshPart it replaces the texture maps of the model's material named by its `MaterialName`. The properties are in `docs/rendering/models.md` (maps are texture paths in the project, such as `"assets/textures/wood.png"`). `Part.TileSize` is how many studs one copy of those textures covers (default 8; 0 leaves the shape's coordinates unscaled). `Enum.TextureChannel` (`Red`, `Green`, `Blue`, `Alpha`) is for its `…Channel` properties, which also take item names (`look.RoughnessChannel = "Green"`).
