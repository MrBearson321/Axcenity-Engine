# Sound

Playing project audio from Lua.

- **Sound** (Phase 29, extended after it): put a `Sound` Instance in the Workspace (or a part), set `SoundId` to a project-relative audio file (such as `"assets/audio/chime.wav"`), then call `sound:Play()` (from the start) or `sound:Stop()`. `sound:Pause()` and `sound:Resume()` carry on from where it was. `Playing` is true while it plays: setting it to false pauses and true resumes, and a Sound saved with `Playing` true starts when the game starts, with no script. `Volume` is a non-negative linear amplitude multiplier (1 is original level, 0 is silent), `PlaybackSpeed` scales speed and pitch (1 is normal, from 0.01 to 20), and `Looped` repeats the entire file; changes to all three apply to a sound that's already playing. `Spatial`, off by default, places the sound in the world: it pans in stereo as the camera turns and gets quieter with distance, full within `RollOffMinDistance` studs (10) and silent from `RollOffMaxDistance` (150). Its place is the nearest ancestor `Part`, `MeshPart` or `Terrain`, and `Sound.Position` when it has none of those. A non-spatial sound ignores position. `Ended` fires (on both sides) when a sound that isn't looped plays to its end, after `Playing` goes false; `Stop` doesn't fire it. Supported files are WAV, FLAC, Ogg Vorbis and MP3. Playback runs in the host, not Lua (see `GameAudio` in `audio`); stopping editor Play drops its audio and stops all playback. `examples/hello-spatial` is two bells you can fly between.
