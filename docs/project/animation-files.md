# Animation files

The JSON for take clips, property clips, and animator controllers.

- **Animation files** (Phase 38, `anim::files`): pretty JSON, written with every field in a fixed order (`to_json`, through a `.saving` temporary file), so saving the same thing gives the same text; unknown fields are errors that name the line. Paths in them are from the project folder.
  - A **take clip** (`*.anim.json` without `"kind"`): `{ "format_version": 1, "source": "assets/models/noodle.fbx", "take": "Moves", "start": 0.0, "end": 1.0, "speed": 1.0, "loop": true, "root_motion": false, "events": [ { "time": 0.5, "name": "Wave" } ] }`. `start` and `end` are seconds in the take; `speed`, `loop`, `root_motion` and `events` may be left out (1, true, false, none). An event's `time` is seconds from the clip's start. Used by skeletal Animators / controllers.
  - A **property clip** (`*.anim.json` with `"kind": "property"`): `{ "format_version": 1, "kind": "property", "duration": 1.5, "loop": false, "tracks": [ { "id": "position", "target": ".", "property": "Position", "keys": [ { "id": "k1", "time": 0.0, "value": [0, 2, 0], "interp": "Linear" }, { "id": "k2", "time": 1.5, "value": [0, 8, 0], "interp": "Linear" } ] } ], "events": [ { "time": 1.5, "name": "Opened" } ] }`. `duration` is explicit (seconds); keys must lie in `0..=duration`. `target` is relative to the Animation Instance's parent: `.` is that Part, Model or ScreenGui, and `Hinge/Panel` is a descendant by names (`anim::target_path` makes these). `property` is `Position`, `Orientation`, `Size`, `Color`, `Transparency`, `BackgroundColor3`, `BackgroundTransparency`, `TextColor3`, `TextSize` or `ImageTransparency`. A key's `value` is the property's numbers (v3 Phase 5): `[x, y, z]` for a Vector3 (Orientation in degrees), `[r, g, b]` from 0 to 1 for a Color3, `[x_scale, x_offset, y_scale, y_offset]` for a UI element's UDim2 `Position` or `Size`, and `[n]` for a number. Every key on a track has the same count, which must fit the property; it's applied by the target's own property kind. Older clips (three-number Position/Orientation/Size keys) have the same file shape, so they open unchanged (no migration). Values are where things are in the world, as Properties shows them. On a **Model**, `Position` and `Orientation` are its pivot: the middle of the box around its parts when it first plays, turned from how it was built; every part inside moves with it. A Part whose `Position` or `Orientation` is animated carries the parts inside it (a door's Panel inside its Hinge). Parents are applied before children, so a child's own tracks win. `interp` is `Step` or `Linear` (Orientation uses quaternion slerp; everything else goes straight between numbers). Played by an `Animation` Instance (`anim::PropertyPlayers`). The Animation tab's New ▸ Property clip makes these (see `docs/editor/import.md`).
  - A **controller** (`*.controller.json`): `{ "format_version": 1, "parameters": [ { "type": "Bool", "name": "IsGrounded", "default": true }, { "type": "Number", "name": "Speed", "default": 0.0 }, { "type": "Trigger", "name": "Jump" } ], "default_state": "Idle", "states": [ { "name": "Idle", "motion": { "clip": "assets/animations/noodle/Idle.anim.json" }, "speed": 1.0, "position": [0.0, 0.0] } ], "transitions": [ { "from": "Any State", "to": "Jump", "conditions": [ { "parameter": "Jump", "test": "Triggered", "value": 0.0 } ], "blend": 0.25, "exit_time": null, "interruptible": false, "priority": 0 } ] }`. `position` places a state in the editor's graph. Condition tests are `IsTrue`, `IsFalse` (Bools), `Triggered` (Triggers), `Greater` and `Less` (Numbers, against `value`). An empty or unknown `default_state` starts in the first state. A state's clip may be `""` (no clip: it holds the rest pose). A state can have a Return setting (Phase 42): `"returns": { "to": "Idle", "when": "finished", "blend": 0.25 }`, where `when` is `"finished"`, `{ "bool_is": { "parameter": "IsAttacking", "value": false } }`, `{ "triggered": { "parameter": "Land" } }` or `{ "after": { "seconds": 2.0 } }`; the transition it makes is saved too, with `"generated": true` (and made again when the file is loaded, so a hand-edited setting works). A state's `motion` can also be a blend tree (Phase 41): `{ "blend_tree": { "parameter": "Speed", "children": [ { "clip": "assets/animations/noodle/Idle.anim.json", "threshold": 0.0 }, { "clip": "…/Walk.anim.json", "threshold": 2.0 } ] } }`. `exit_time` is `null` or how much of the state's clip (1 is once through); see `docs/rendering/animation.md` (Transitions) for how they run. `any_state_position` (where the editor draws the Any State) is written only once it's been moved.
  - `examples/hello-animation` has a generated rig (`noodle.fbx`, from `assets` `model/test_rig.rs`; a test checks it's up to date, and `AXCENITY_WRITE_EXAMPLES=1` rewrites it), four clips and a controller; tests check those files are saved as the engine writes them.
