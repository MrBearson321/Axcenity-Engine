# Model Studio

The Model Studio tab (Phase 55) edits a model's meshes inside the editor and saves them as a `.glb`. The tab is `editor/src/model_studio.rs` (state, toolbar, keys, undo), `model_studio/view.rs` (3D view, picking, handles, overlay), `model_studio/modal.rs` (G, R and S), `model_studio/tools.rs` (modeling operations' keys, menus, the knife, loop cut and adjust panel; Phase 56) `model_studio/proportional.rs` (proportional editing and pivots), `model_studio/modifiers.rs` (the Modifiers panel; Phase 57), `model_studio/uv_editor.rs` (the UV menu and the UV editor pane; Phase 58), `model_studio/paint.rs` (Paint mode and its panel; Phase 59) `model_studio/sculpt.rs` (Sculpt mode and its panel; Phase 60) and `model_studio/retopo.rs` (the Retopology and Bake sections, Poly Build; Phase 61); its app actions are `editor/src/app/model_studio.rs`. The meshes are `mesh_edit`'s `EditMesh`, `ModelDoc`, `Selection` and `PrimitiveSettings`; the operations are `mesh_edit::apply` and `MeshOp` (`mesh_edit/src/ops.rs` and `ops/`); the modifiers are `mesh_edit::Modifier` and `evaluate` (`modifiers.rs` and `modifiers/`), kept in the sidecar by `sidecar.rs`; unwrapping is `mesh_edit::uv` (`uv.rs` and `uv/`); painting is `mesh_edit::paint` (`paint.rs` and `paint/`); sculpting is `mesh_edit::sculpt` (`sculpt.rs` and `sculpt/`); retopology is `mesh_edit::retopo` (`retopo.rs`) and baking `mesh_edit::bake` (`bake.rs`).

## Opening and New

- **Open** in the tab lists the project's models. **Edit in Model Studio** is on a model's menu in the Assets panel and in a MeshPart's Properties (`Edit::OpenInModelStudio`); a `MeshId` pick (`file.glb#Chair`) makes that object the active one.
- `ModelDoc::open` reads the file through `assets` (`list_objects`, then one `load_models` call with a pick per object), so it reads a file exactly as a MeshPart does. Each object is where it is in the file (node transforms applied), back in the file's units, welded by position into polygons (`mesh_edit::from_model`). Groups stay in the object list.
- A `.glb` saves over itself. An `.fbx` or `.gltf` saves as `<name>.glb` beside it (the original stays).
- **New** makes a cube, plane, UV sphere, ico sphere, cylinder, cone or torus (`PrimitiveSettings`: size, height, thickness, segments, rings, subdivisions; Y up, centred on the origin). It saves as `assets/models/<Shape>.glb` (a number after the name if it's taken).
- Opening while the open model has unsaved changes asks first.

## The mesh

`EditMesh` (`mesh_edit/src/half_edge.rs`) is a half-edge mesh of n-gons: each corner's half-edge carries its uv (and a second uv, `uv2`, when the mesh has one) and normal, so uv cuts and hard edges need no split vertices; each face has a material slot and is smooth or flat. An edge with one face (an open border) or more than two has half-edges without twins. Moves keep vertex and face numbers, so selections hold them; an operation builds a new mesh and leaves its own selection. Moving vertices reshades the faces around them (flat: the face's normal; smooth: the angle-weighted average of the smooth faces at the vertex; with **auto smooth** on the mesh, only the smooth faces reached without crossing an edge sharper than its angle); faces nobody moved keep the file's normals exactly. N-gons are triangulated by ear clipping in their plane (`fill.rs`), and saving writes triangles.

## Modes and picking

- **Object** and **Edit** mode (Tab). Object mode picks objects (click, Shift-click, A) and moves whole objects; Edit mode edits the active object.
- Vertex, Edge, Face (1, 2, 3; switching keeps what's covered). Click, Shift-click (toggles), box (left drag in Edit mode), loop (Alt-click), linked (L), all (A), grow and shrink (Ctrl + / Ctrl − or Ctrl =; taken before egui's zoom).
- Loops (`edge_loop`): straight on across a vertex with four edges; along the border of a face with more than four sides (a cylinder's cap rim); along an open border. In Face mode Alt-click picks the ring of quads the edge crosses (`face_loop`).
- Picking ignores what's hidden behind the mesh (the overlay is X-ray): vertices and edges by distance on screen, faces and objects by ray.

## Moving

- **G, R, S** (`modal.rs`): follow the mouse; X, Y, Z lock to that world axis, again for the Local axis, a third time free; typed numbers (studs, degrees, a factor; `-` flips the sign); Enter or click keeps it, Esc or right-click cancels. G again during a grab is **edge slide**.
- **Pivot** (the toolbar's crosshair menu): Median Point, Bounding Box Center, 3D Cursor, or Individual Origins (each connected part, or in Object mode each object, round its own middle). The handles always go round their box.
- **3D cursor**: Shift+right-click puts it on the surface under the mouse (or level with where it was); Shift+C or the menu's Cursor to World Origin puts it back; Cursor to Selected moves it to the median. Merge At Cursor and Spin use it.
- **Proportional editing** (O, or the dashed circle): in Edit mode, every vertex within the radius of a picked one takes part of the move, by the falloff (Smooth, Sphere, Root, Inverse Square, Sharp, Linear, Constant) of its distance to the nearest picked vertex. During a move the wheel or Page Up/Down changes the radius (the wheel doesn't zoom then), and a circle shows it. Turns turn part of the way (`proportional::partial` slerps); moves and scales go part of the way.
- **Handles**: the Studio toolbar's Move, Rotate and Scale show the editor's own gizmo (`gizmo.rs`) on the box around what's picked. The gizmo drags the view's own MeshPart's pose, and `view::pose_change` turns the change of pose into a matrix for the vertices (a flat side of the box isn't scaled).
- Snapping is the editor toolbar's (Phase 8b): moves in move steps, turns in rotate steps, scales in tenths. Ctrl flips it. **Local** axes put Y along the picked faces' normal (or the picked corners'); Object mode has no local axes.

## Modeling operations (Phase 56)

`mesh_edit::apply(mesh, selection, op)` runs a `MeshOp` and returns the new mesh and what's picked after (the new faces, loops or vertices, in the same select mode), or an error to show. Each takes the mesh apart into a `Soup` of polygons, edits that and builds a new `EditMesh`: faces cleaned of repeated corners (a corner that comes back splits the face), unused vertices dropped, changed faces and their smooth neighbours shaded again.

| Operation | Key | What it does |
|---|---|---|
| Extrude | E | Picked faces pushed out with walls round them: by region (average normal), individual faces, or along normals (even thickness). With no faces, picked open-border edges pull out into faces. |
| Inset | I | A smaller copy inside each region (or face), joined by a ring of quads; depth pushes it out or in. |
| Bevel | Ctrl+B, Ctrl+Shift+B | Edges (between two faces) or corners cut off, width, segments and profile (0.5 round, 1 square, 0.25 flat; a superellipse). Corners move in from both beveled edges, or slide along an unbeveled one; strips run along the edges; a patch fills each corner, except that a lone face with neither edge beveled takes the gap in (a bevel's end), and two strips whose profiles join the same points share them (a beveled loop's mitred corner). Width stops at 0.45 of the shortest edge at a beveled corner. Needs a closed fan of faces round each corner. |
| Loop Cut | Ctrl+R | Hover an edge to see the loop; the wheel sets the cuts; click cuts across the ring of quads it crosses (stopping at other faces or open borders, which take the new points) and then slides. |
| Edge Slide | G G | Picked edges' ends slide along the edges beside them; the sign picks the side. |
| Knife | K | Click on edges or corners (snapping to vertices); Enter or Space cuts each pair in a row across the face they share; Backspace drops a point. Points inside a face aren't supported. |
| Bridge Edge Loops | Mesh menu | Two picked closed loops of open-border edges with as many edges, joined vertex to vertex at the turn that makes the shortest joins. |
| Merge | M | At Center, At Cursor, or By Distance (sorted along X, union-find); faces that end up back to back go. |
| Delete, Dissolve | X or Delete | Delete Vertices, Edges, Faces or Only Faces (keeps the vertices); Dissolve Vertices, Edges or Faces joins the faces round them into one (if their border is one loop), and drops corners left between two edges. |
| Fill, Grid Fill | F, Mesh menu | A face across each picked open-border loop; or a Coons-patch grid of quads across one loop with an even number of edges (span 0 is the squarest; offset turns it). |
| Subdivide | Mesh menu | Picked faces' edges cut in `cuts + 1`: quads into grids, triangles into triangles, other faces into a fan round their middle; neighbours take the points. |
| Spin | Mesh menu | Picked faces (or open-border edges) extruded in steps round an axis through a center (the cursor); a whole turn welds the end to the start and drops the end faces. Points on the axis weld. |
| Flip, Recalculate | Alt+N, Shift+N, Ctrl+Shift+N | Turn faces over; or make each connected part agree with its neighbours and face out (or in), by its signed volume. |
| Shade Smooth, Flat, Auto Smooth | Mesh menu | Picked faces (whole objects in Object mode, the only operations there); Auto Smooth sets the mesh's angle. |

- Every operation keeps a manifold mesh manifold (`mesh_edit::check_manifold`: each edge one or two faces running opposite ways, one fan of faces round each vertex); only Delete opens a closed one. Flipping some faces of a closed mesh makes its edges disagree until Recalculate.
- E, I, Ctrl+B, G G and a loop cut's click run the operation at nothing and then follow the mouse with its main value: the extrude's distance (where the mouse's ray passes nearest the normal's line), the inset's thickness and bevel's width (how much farther from the middle the mouse is), or the slide (sideways). Typing a number sets it; the wheel changes a bevel's segments; click or Enter keeps it; Esc or right-click takes the operation back with nothing to redo. The Mesh menu runs each with settings sized to the mesh.
- **Adjust last operation**: after an operation, a panel at the view's bottom left shows its settings (`tools::settings_ui`). Changing one runs it again from the state before it (`StudioDoc::adjust`), replacing its result without another undo step. Any other edit, a pick, an undo or a mode change closes the panel.

## UV unwrapping (Phase 58)

`mesh_edit::uv` changes only corners' uvs, in channel 0 or the second channel (1, for lightmaps later); vertex, face and half-edge numbers stay. Uvs are glTF's ((0, 0) the texture's top left, v down); the flattening works v-up, so a face seen from outside is counter-clockwise and a texture isn't mirrored. The tools work on the faces picked in Edit mode, or every face of the active object when none are; each is one undo step (`StudioDoc::edit_uvs`), and an object whose file had no uvs saves them from then on (`DocObject::uvs`).

- **Seams** (`EditMesh::seams`, by their two vertices; Mark Seam and Clear Seam on the picked edges) draw red over Edit mode's edges. **Pins** (`EditMesh::pins`) are by vertex. Operations keep both (renumbered; a seam whose edge an operation split or removed goes), and keep the second uvs of faces they didn't change (new or changed faces get zeros).
- **U** in the 3D view (Edit mode), or the toolbar's **UV** menu: Mark and Clear Seam; **Unwrap** (faces cut into charts at seams, each flattened by LSCM, least squares conformal maps, solved as sparse least squares by CGLS in `uv/sparse.rs`; two pins hold each chart: its pinned uv vertices, or else the two farthest apart in a projection on its average normal, at their projected places; then the charts without pins are packed); **Smart UV Project** (a direction for each face more than the angle limit, 66° by default, from all so far, biggest faces first, each direction moved twice to the area-weighted middle of its faces; faces with the same direction joined across edges that aren't seams make a chart, flattened by LSCM from that projection, or left as the projection if LSCM turns a triangle over; then scaled alike and packed); **Cube**, **Cylinder** and **Sphere Projection** (round the picked faces' box, its largest side; a face across the back of a cylinder or sphere takes its small us round past 1); **Project From View** (through the view's camera, fitted into the texture keeping its shape); **Pack Islands**; **Average Island Scale**; the margin, angle limit and whether Pack turns islands; Clear UV 2.
- **Pack** (`uv/pack.rs`): each island without a pin is turned to its smallest box (along an edge of its convex hull, then on its side if taller than wide), the boxes put in rows from the tallest, at the row width (tried from the square root of their area up) that gives the smallest square, and scaled into the texture: `margin` between islands, half that round the edge. **Average Island Scale** scales each island round its middle so its uv area over its surface area is the mean.
- **Stretch** (`uv::stretch`): per face, `angle` is the average of how far each corner's angle moved as a share of itself, and `area` is 1 − min(r, 1/r), r being the face's uv area over its surface area against the whole selection's.
- **Islands** (`uv::uv_islands`) are faces joined across edges whose uvs match on both sides. `uv::overlapping_islands` names the pairs whose triangles overlap by more than touching.

### The UV editor

The toolbar's square-grid button opens a pane beside the 3D view (below it when the tab is narrow) showing the faces the tools work on, in the texture's square under an 8 × 8 checker.

- Vertex, Edge, Face and Island picking: picks are corners, a uv vertex being every corner of a vertex with the same uv (Blender's shared location). Click (Shift toggles), drag a box (whole faces, or islands touched, in those modes), A for all. The picks are dropped when the mesh is rebuilt.
- **G, R, S** move, turn and scale the picked uvs round their box's middle with the mouse; X and Y hold a move or scale to that axis; click or Enter keeps it as one undo step ("Move UVs"), right-click or Esc puts it back. A middle or right drag slides the view; the wheel zooms.
- **P** pins, **Alt+P** unpins (the picked corners' vertices, or Edit mode's picked vertices), **V** stitches (corners of one vertex with different uvs go to their middle), Align X and Align Y (the same u, or v, as their average); Pack and Average Island Scale are in its Edit menu too.
- **UV 1 / UV 2** picks the channel everything works on. **Stretch** colours faces by angle or area, blue for none through red for much. The **checker** button draws the model in the 3D view with an 8 × 8 black-and-white checker on that channel (`ModelDoc::to_model_on`) in place of its materials. A hint says how many island pairs overlap.

## Texture painting (Phase 59)

**Paint** on the toolbar's mode switch (beside Object and Edit; Tab goes back to Object mode) paints the active object's material maps. The side panel shows the Paint panel in place of Modifiers: the material slot, the resolution (256 to 4096, chosen before the slot's first stroke), the map, its layers and the brush.

- **Maps** (`MapKind`): base color, roughness, metalness, height, emissive and ambient occlusion. A `PaintSet` (`DocObject::paint`, one per slot) holds a `PaintMap` per map painted: the material's own value as its `fill` under a stack of `Layer`s, bottom first. A slot's first stroke starts the set (with the base color map); a stroke on a map not there yet adds it. The material's texture for a map, times its factor, becomes an opaque "Base" layer (a base color's alpha is kept apart, under the paint), and the factors go to 1 so the paint is what's drawn. Roughness and metalness come together, since glTF saves them as one texture. A material with a uv transform has every textured map brought in (resampled through it) and the transform taken off, since paint is on the mesh's own uvs; a normal map it had isn't resampled.
- **Layers** have a blend mode (Normal, Multiply, Screen, Overlay, Add, Subtract, Darken, Lighten), opacity, visibility and an optional mask (Add Mask; **Paint on** Layer or Mask: Draw shows the layer, Erase hides it). Each map keeps its layers flattened (`PaintMap::flat`), updated at the texels a dab touches; the material gets the flattened image while painting (`PaintSet::apply_map`), so the view and the UV editor draw it at once. Color maps are sRGB, as their PNGs; blending is in those values.
- **Brushes** (`paint/brush.rs`): Draw, Soften (3 × 3 blur), Smear (drags by the stroke's move, turned into uvs on each texel's triangle), Clone (Ctrl-click sets the source; copies the map as the stroke began, shifted by source − first dab), Fill (the part clicked, faces joined across edges; in the UV editor, the uv island) and Erase. Radius (points on screen; `[` and `]`), strength, falloff (Smooth, Sphere, Root, Sharp, Linear, Constant), spacing (a share of the radius between dabs). X swaps Draw and Erase. **Image**: a project image as a stencil (fixed on the view, Alt-drag moves it, drawn faintly over it) or a texture brush (fills each dab's circle); its color is painted (grey maps take its luminance) and its alpha is how much. **Symmetry** X, Y, Z mirrors each dab across the object's origin planes. **Pressure**: a pen's force (egui touch events, where the platform reports it) scales the radius and/or strength.
- **The 3D view** (`TexelMap`, `paint/texels.rs`): the slot's triangles are drawn into uv space once per mesh (the cached triangle-ID buffer), giving each covered texel its place and normal on the surface; a gutter a few texels deep (size / 128, 2 to 16) round each island carries its triangle's plane on. A dab covers the texels within its radius on the surface (the screen radius at the hit, in studs), by falloff, times how far each faces the way the hit face does (full to 45°, none side-on), so strokes don't paint through thin parts. Texels either side of a uv seam, and the gutter the GPU's filter reads, get the same paint, so seams don't show. Faces whose uvs overlap (a New cube's six squares) each have the texel. The view draws the evaluated mesh but paints on the object's own mesh; while a stroke paints only materials are put in again (`Model::with_materials`, keeping the meshes' keys), and a height map's normal map is made when the stroke ends.
- **The UV editor** in Paint mode shows the map under the uvs and paints in uv space (no picking).
- Each stroke is one undo step ("Paint Stroke", "Fill"; a slot's first starts the set inside it); adding, deleting, moving, hiding and masking a layer are a step each, and a slider drag is one step.
- **Saving** (`ModelDoc::bake_paint`) writes each painted map, flattened, to `textures/<model>_<object>_<material>_<Role>.png` beside the model: `BaseColor`, `Emissive`, `Occlusion` (grey), roughness in green and metalness in blue of one `MetallicRoughness`, and height turned into a tangent-space `Normal` (`normals_from_height`: green up the texture; Bump 1 makes the whole height range a 32nd of the texture's width). `assets::texture_roles` reads those names by role. The material is pointed at them, so the `.glb` links them and MeshParts draw them with no setup. Other objects' materials of the same name (LOD copies) get the same maps. Hidden layers aren't in the saved maps.
- **The sidecar folder** `<model>.meshedit/` (`mesh_edit::paint_folder`, `assets::MESH_EDIT_FOLDER_SUFFIX`) keeps each layer, mask and base alpha as a PNG (`<object>-<slot>-<Map>-<layer>.png`, `-mask.png`); the sidecar JSON keeps their names, order, visibility, opacity and blend, each map's fill and the set's size and bump. Save replaces the folder's files (a deleted layer's goes) in the same history step as the `.glb`; opening reads them back (`ModelDoc::read_sidecar_with`) and puts the sets on the materials. The Assets panel doesn't list the folder, and built games leave it out.

## Sculpting (Phase 60)

**Sculpt** on the toolbar's mode switch (Tab goes back to Object mode) sculpts the active object. The side panel shows the Sculpt panel: the brush, the mask and the detail.

- **The sculpt** (`mesh_edit::Sculpt`): the object's vertices (the same numbers as its `EditMesh`), its faces and those cut into triangles, each vertex's faces, triangles and neighbours (along the faces' edges), a mask, a smooth normal per vertex (Newell normals of its faces, so a quad's diagonal doesn't tip it and mirrored faces give mirrored normals), and a bounding volume hierarchy of the triangles (`sculpt/bvh.rs`: median splits, leaves of 8, refitted bottom-up round what moved). Rays and brushes go through the hierarchy; the ray test is in f64, so a ray along a shared edge doesn't slip between its triangles. The sculpt is made from the mesh when Sculpt mode first needs it, and again when the mesh changed some other way (an undo, an operation); the mask stays if the vertices are the same.
- **Brushes** (`SculptTool`, `sculpt/brush.rs`): Draw (along the area's normal), Clay Strips (up to a plane over the area, in a square along the stroke; its first dab is round), Smooth (toward the neighbours' middle), Grab (what was within the radius when the stroke began, by the mouse's move), Inflate (along each vertex's normal), Crease (in, with the sides pinched together), Flatten (toward the area's plane), Pinch (toward the brush's middle along the surface), Snake Hook (what was under the brush pulled to where it is, each dab) and Mask. The area is the falloff-weighted middle and normal of what's within the radius. Ctrl is the other way (Smooth has none; Mask takes it off); Shift smooths, whatever the brush. Grab and Snake Hook drag on the plane facing the camera through where they took hold, at the radius they took hold with, and strength doesn't change them.
- **Settings** (`SculptBrush`): radius (points on screen; `[` and `]`), strength, falloff (the paint brushes' curves), spacing (a share of the radius between dabs), X, Y and Z symmetry (X is on at first), and pen pressure on the radius and/or strength (egui touch events, where the platform reports it). **Symmetry** mirrors each dab across the object's origin planes. A dab works out its moves for itself and each mirror image from where the vertices are before it, adds them up and only then moves them, so a mirrored mesh stays mirrored.
- **Masks**: a vertex's mask (0 to 1) holds back every brush's move by that much, so a fully masked vertex never moves. The Mask brush paints it; Invert, Clear, Hide Masked (hides each triangle with a vertex masked at least half; brushes, rays and the view pass them over) and Show All are in the panel. Masked triangles are drawn dark grey. The mask isn't an undo step and isn't saved.
- **Detail** (`sculpt/remesh.rs`): **Voxel Remesh** samples the distance to the surface on a grid a voxel size apart, centred on the mesh's box (inside where a row along X has crossed the surface an odd number of times; a crossing on a shared edge counts for one of its triangles, by a rasterizer's top-left rule), and puts quads through it by surface nets: closed, smooth, slot 0, without uvs or seams. More than `MAX_VOXELS` (160³) grid points is refused. **Subdivide** is one level of Catmull-Clark (the Subdivision Surface modifier's). Each is one undo step.
- **Drawing**: the triangles are split into chunks of the hierarchy, at most `CHUNK_TRIANGLES` (4096) each. While sculpting, the view leaves the object out of its model (`ModelDoc::to_model_except`; with nothing left, the MeshPart is hidden) and draws each chunk as a mesh of its own (clay, and masked), in the object's space. A dab marks the chunks whose corners it changed (`Sculpt::take_dirty_chunks`); only those are made again, with the same key and a new version, so the renderer writes their corners over its copy (`MeshSource::version`). New triangles (after masking or hiding) take a new key. There's no overlay, and modifiers aren't shown while sculpting.
- Each stroke is one undo step ("Sculpt Stroke"): the vertices it moved go back into the mesh when it ends (`Sculpt::write_back`), which reshades the faces round them.
- **Performance**: on a 500k-triangle sphere, every brush with X symmetry takes about 1 ms of CPU a frame (the pick, the dab, and the touched chunks' corners), against the 33 ms of 30 frames a second (`sculpting_a_500k_triangle_mesh_stays_above_30_frames_a_second` prints the times). Making the sculpt takes about 0.2 s; a stroke's end puts its vertices back in tens of ms.

## Retopology and baking (Phase 61)

In Object and Edit mode the side panel has **Retopology** and **Bake** sections under the modifiers.

- **Reference**: another object of the model (a sculpt), picked in the panel; not an undo step. It's kept as a `mesh_edit::Reference` (its triangles in the sculpt's bounding volume hierarchy, with the nearest-point and any-hit queries `bvh.rs` adds), made again when its mesh changes (`RetopoState`, keyed by a hash of its positions). Objects have no transforms of their own, so the reference and the low-poly object share the file's space.
- **Snap to surface** (on at first): in Edit mode on another object, a move (G, R, S or the handles) puts each vertex it moves on the reference's nearest point, and an operation puts the vertices it makes or moves (those not where one was before) there (`ModelStudio::refresh_snap` sets `StudioDoc::snap` before each). An extrude then slides along the surface rather than lifting off it.
- **Poly Build** (a toggle; Edit mode): a click on the reference adds a point, and the fourth makes a quad turned to face the camera; a click with an open edge of the active object within 24 points makes a quad out from that edge to the click, its new edge as long as the open one with the click in its middle (`mesh_edit::poly_build`, `PolyStep`). New corners go onto the reference and weld to a vertex within 12 points. Each quad is an undo step ("Poly Build") and is picked. Backspace drops a point; Esc or a right-click ends the tool.
- **Make Low Poly**: the reference (with its modifiers) cut to the panel's triangle count by meshoptimizer (`decimate_to`, the Decimate modifier's simplifier, aimed lower until under the count), evened out on the reference three times (`relax`: each vertex halfway to its neighbours' middle and back onto the surface, which opens out triangles the decimation folded across a ridge), and unwrapped by Smart UV Project at 45° (tighter than the UV menu's 66°, so fewer faces are squashed at a chart's edge). It's a new object `<name>_Low` after the reference (and what's inside it), with its materials, made the active one; one undo step.
- **Bake** (`ModelDoc::bake`, `bake.rs`): the reference onto the active object's first uvs, each material slot of it, both with their modifiers on as saved. For each texel of a `TexelMap` (so each island's gutter is baked too), a ray starts at the cage (the place pushed out along its normal by the cage distance; Auto is a fiftieth of the reference's box diagonal) and goes back in; the first point of the reference within twice the cage is what it shows, else the nearest point (a miss; misses on more than 1% of the surface's texels are warned about). Texels are split among threads; results are written in a fixed order.
  - **Normal**: the reference's shaded normal in the low-poly surface's tangent frame: tangents are `assets::tangents` over the slot's corners joined as the `.glb` joins them (vertex, uvs, normal), blended as the GPU blends them, the up direction scaled by the blended side as `surface_normal` in `shader.wgsl` does (a value past ±1 is scaled back with the others, since the shader normalizes). Green is up the texture; **DirectX normal map** flips it and names the file `_NormalDX.png`, which `assets` reads as one in a glTF file too.
  - **Occlusion**: the share of rays (16 by default) from the reference's point, cosine-spread over its sky by a Hammersley set turned by each texel's own angle, that meet nothing within the occlusion distance (Auto: a tenth of the size).
  - **Curvature**: the reference's mean curvature (per vertex from its neighbours' heights over its plane, smoothed once), as 0.5 + 0.5·tanh(k × size / 50): brighter on bulges, darker in hollows.
  - **Base color**: the reference's paint (its base color `PaintSet`), or its material's texture times its color, or its color, at the point's uv.
  - The maps are PNGs in `textures/` beside the model, named as painted maps are (`<model>_<object>_<material>_Normal.png`, `_NormalDX`, `_Occlusion`, `_Curvature`, `_BaseColor`), and the material links the normal, occlusion and base color maps (factor 1, uv transform off); curvature isn't drawn by materials. The app writes them as one step of the editor's history ("Bake <object>"; `bake_model_studio`), and the material change is a step of the Studio's; Save then links them in the `.glb`. Texels off the islands and gutters take the islands' mean color. A painted slot's paint is saved over the baked base color at Save.
  - **Overlaps**: islands of a slot whose uvs overlap (`uv::overlapping_islands`) share texels, so one shows the other's bake. The report names each pair ("UV islands 1 and 2 overlap (1 and 1 faces)…", numbered as `uv_islands` lists them) in the panel and the Output, and **Pick Overlapping** picks their faces in Edit mode.
- A bake runs while the UI waits, its texels split among threads; the tests bake the 28k-triangle face onto 4k triangles at 1024 in well under two seconds in a debug build (`mesh_edit` is optimized there).

## Modifiers (Phase 57)

Each object has a stack of `Modifier`s (`ModifierKind` and `show`), in the side panel under the object list (which is always shown now). The mesh itself doesn't change: `mesh_edit::evaluate(mesh, stack, purpose)` runs the shown ones in order on a copy, the view draws that (`Purpose::Viewport`) with the object's own cage over it, and Save writes it to the `.glb` (`Purpose::Export`). A modifier that can't run is passed over, and the panel shows why under it.

| Modifier | Settings | What it does |
|---|---|---|
| Mirror | axis, clipping, merge, distance | A reflection across the plane through the object's origin square to the axis (the file's own axes: objects have no transform of their own). Merge puts vertices within the distance of the plane on it, shared with their reflections, so an open half closes; faces lying in the plane go. Clipping keeps Edit mode moves (keys, handles, proportional editing) from taking a vertex across the plane, and one on it stays on it (`mesh_edit::clip`). |
| Subdivision Surface | viewport and export levels (0 to 6) | Catmull-Clark: a quad per corner each level, points moved toward the smooth surface. Open borders stay put, smoothed along themselves; edges with more than two faces are pinned; uvs are carried linearly. Over 2 million faces is refused. |
| Array | count (to 256), offset, merge, distance | Copies, each `offset` times the mesh's size from the last (1, 0, 0 puts them side by side). Merge joins a copy's vertices to the last copy's within the distance and drops faces left back to back. |
| Solidify | thickness, offset (−1 to 1) | A second skin along each vertex's normal: −1 behind the surface, 1 in front of it, 0 either side; open borders get a rim of quads. |
| Bevel | width, segments, angle | Edges whose faces meet at more than the angle, beveled round by the Bevel operation. |
| Decimate | ratio | Triangles cut to that share by meshoptimizer (`meshopt::simplify`, no error limit); corners with their own uv or material are kept apart, so seams and material borders stay. Each triangle is smooth if most of its material's faces were. |
| Triangulate | — | Each face cut into triangles, keeping corners' uvs and normals. |

- The panel's Add Modifier menu, the eye (show or hide), up and down, ✓ (Apply) and × (remove) are an undo step each; a setting's change is a step, and a drag or a typed number joins one step until it's let go (`StudioDoc::set_modifiers`, `end_modifier_edit`).
- **Apply** runs that modifier alone on the mesh (as Blender does, without the ones before it) with its viewport settings, takes it off the stack and clears the selection, as one undo step (`StudioDoc::apply_modifier`).
- **Generate LODs** (`ModelDoc::generate_lods`) puts `<name>_LOD1` and `<name>_LOD2` after the active object (and what's inside it), at its depth: its mesh and stack with a Decimate to half, then a quarter (`LOD_RATIOS`, as the renderer's own copies), replacing copies already there, as one undo step. They're named as `assets` reads levels of detail ([rendering/models.md](../rendering/models.md)), so a MeshPart using the file, or picking the full object, draws them far away with no other step. The view doesn't draw them (`ModelDoc::is_lod_copy`); the object list says so on hover.

### The sidecar

`<model>.meshedit.json` beside the `.glb` (`mesh_edit::sidecar_path`, suffix `assets::MESH_EDIT_SUFFIX`) keeps, for each object with a stack, seams, pins, second uvs or paint, its place and name, its mesh (positions, faces' corners, uvs, second uvs, normals, material slot and smoothness, auto smooth, seams, pins), its slots' material names, the stack and its paint sets. It holds a 64-bit FNV-1a hash of the `.glb` it was saved with. Opening a `.glb` reads it (`ModelDoc::read_sidecar`): each object is found by place and name, or name; its faces' slots are matched by material name. A sidecar whose hash doesn't match (the `.glb` was written by another program since) isn't used, with a warning in the Output, and the object opens as its saved result. Save writes it with the `.glb` as one history step, or deletes an old one once no object needs it. Built games leave sidecars out (`project::packed`). Paint layers (Phase 59) are in the sidecar folder beside it (see Texture painting). A sculpt is the mesh itself; masks aren't kept.

## Undo and saving

- While the mouse is over the tab, Ctrl+Z and Ctrl+Y are the Studio's (`EditorApp::undo` asks `model_studio.has_pointer()` first), and the F3X single-letter tool keys are off. Each move, handle drag, keyboard move or operation is one step; a step puts back the meshes, mode, active object and selection. Picking alone isn't a step.
- **Save** (`save_model_studio`) writes `ModelDoc::write_glb` (each object's mesh with its modifiers on, at export levels) and the sidecar: a node per object (no transform) under nodes for its groups, so object paths still pick the same objects; a primitive per material slot used; uvs as `TEXCOORD_0` and second uvs as `TEXCOORD_1`; materials deduplicated across objects, with base color, metal-roughness, normal (and scale), occlusion (and strength), emissive textures linked by file relative to the model, alpha mode and cutoff, double-sided, and `KHR_texture_transform` when the uvs are moved. A texture with no file (embedded and never copied out) is left out; importing copies embedded textures out, so imported models keep theirs. The writer is `mesh_edit/src/glb.rs` (serde_json, shared with fracture pieces).
- The save is one step of the editor's history (`History::record_blobs`, "Save <file>"), and `asset_file_changed` reloads the file at once, so MeshParts using it draw the new version that frame. Undoing the save writes the old bytes back and reloads them (`write_package_files`).
