# Default humanoid

The Axcenity default humanoid: a stylized, faceted low-poly person, 1.75 m tall (6.5 heads), in a relaxed A-pose, wearing a charcoal jacket over a light undershirt, dark trousers and low shoes, with a small cyan accent at the cuffs and heel tabs and a small orange tag on the chest. It's an original design with no logo. The design, the decisions and the stages are in [docs/research/default-humanoid.md](../../../docs/research/default-humanoid.md).

Everything here is generated by `build.py` in Blender: no hand-modelled source file. To change the character, change the script and run it again.

| File | What it is |
|---|---|
| `Humanoid.glb` | The default character as one skinned mesh (head and face, eyes, hands, short hair, jacket, shirt, trousers, shoes) on the Axcenity Humanoid skeleton, with the head's 41 face shapes. No file LODs: the engine simplifies it at load. |
| `HumanoidParts.glb` | Every part as its own object on the same skeleton, for swapping: `Head`, `Eyes`, `Hands`, `Body` (a base body under the clothes), `Jacket`, `Shirt`, `Trousers`, `Shoes`, and the hair styles `Hair_Short`, `Hair_Medium`, `Hair_Long` and `Hair_Curly` (Bald is no hair object). Each has `_LOD1` and `_LOD2` copies (Eyes only `_LOD1`), which a MeshPart picking the part brings with it. The objects are inside the armature, so a pick is `HumanoidParts.glb#AxcenityHumanoid/Jacket`. A part MeshPart inside the character's skinned `Body` follows its pose and place (`docs/rendering/animation.md`, Followers; `project::humanoid_part`, `modular_character`). In the engine the default character's `Body` also has sockets on the head, back, hips, hands and feet for accessories, and body sliders as attributes (`docs/rendering/animation.md`, Sockets and Body sliders). |
| `HumanoidAnimations.glb` | The skeleton with no meshes and the 32 starter animations, one glTF animation each, at 30 frames a second. |
| `build.py` | Builds the skeleton, every mesh, materials, skin weights, face shapes and LODs, and exports the three files. |
| `animations.py` | Keys the starter animations on the skeleton (procedural poses, no motion capture). |

## Rebuilding

The script needs Blender 4.2 or later (it was written against 5.x). Either:

```bash
blender -b --factory-startup --python assets/characters/humanoid/build.py -- --out assets/characters/humanoid
```

or, without Blender installed, with the `bpy` module from PyPI (Python 3.13 for bpy 5.x):

```bash
python -m venv .bpy && .bpy/bin/pip install bpy
.bpy/bin/python assets/characters/humanoid/build.py --out assets/characters/humanoid
```

It takes about a minute and prints each part's triangle count. Copy the new files into `examples/hello-humanoid/assets/models/Humanoid/` too.

## Conventions

- **Units and axes:** metres; Blender Z up with the character facing -Y, so the glTF files are Y up facing +Z (glTF's front). Feet on the ground at the origin. The engine's character controller faces -Z, so the default character's MeshPart turns it 180° (`Orientation` Y 180). Placed in the engine at 5 studs tall (1 stud = 0.35 m).
- **Skeleton:** Unity and VRM humanoid bone names, which the engine's retargeting reads as roles with no rig definition: `Root` (on the ground, for root motion), `Hips`, `Spine`, `Chest`, `UpperChest`, `Neck`, `Head`, `Jaw`, `LeftEye`/`RightEye`, and per side `Shoulder`, `UpperArm`, `LowerArm`, `Hand`, three bones for each finger and the thumb (`LeftIndexProximal`, `…Intermediate`, `…Distal`), `UpperLeg`, `LowerLeg`, `Foot`, `Toes`. 57 nodes with the armature.
- **Bone axes** (for keying by hand): +X swings a limb forward, bends an elbow and leans the spine forward; a knee bends with -X; +X on a foot lifts the toes; +Y on the spine or head turns toward the character's left; finger curl is -X. Right-side angles mirror the left (Y and Z negated).
- **Materials** (each its own glTF material, so a SurfaceAppearance's `MaterialName` can tint or texture one): `Skin`, `Eye`, `Iris`, `Pupil`, `Brow`, `Mouth`, `Teeth`, `Hair`, `Jacket`, `Shirt`, `Trousers`, `Shoes`, `Sole`, `AccentCyan`, `AccentOrange` (and `Underwear` on the base body). Flat PBR colours, no textures yet.
- **Face shapes** (on `Head`, at weight 0, relative to the rest face): `Blink_Left/Right`, `Eye_Closed_*`, `Eye_Squint_*`, `Eye_Wide_*`, `Brow_Raise_*`, `Brow_Lower_*`, `Brow_Inward_*`, `Mouth_Smile_*`, `Mouth_Frown_*`, `Mouth_Open`, `Mouth_Wide`, `Mouth_Narrow`, `Mouth_Pucker`, `Mouth_Left`, `Mouth_Right`, `Upper_Lip_Raise` (and `_Left/_Right`), `Lower_Lip_Lower` (and `_Left/_Right`), `Lip_Corner_Pull_*`, `Cheek_Raise_*`, `Cheek_Puff`, `Nose_Sneer_*`, `Jaw_Open` (a corrective for the `Jaw` bone's turn), `Jaw_Forward`, `Jaw_Left`, `Jaw_Right`: the names of the Axcenity facial profile ([docs/research/facial-animation.md](../../../docs/research/facial-animation.md)). The eyeballs follow the eye bones; the teeth and lower lip follow `Jaw`.
- **Animations** (in place unless named `_RootMotion`, where `Root` travels): Idle, Walk, Run, Sprint, WalkBackward, WalkLeft, WalkRight, RunBackward, RunLeft, RunRight, Jump, Fall, Land, Crouch, CrouchWalk, Wave, Point, PickUp, Use, Push, Pull, Interact, Swim, Climb, Sit, Cheer, Clap, Shrug, Dance, HitReact, Walk_RootMotion, Run_RootMotion. Walk covers 1.45 m/s, Run 3.6, Sprint 6.0, CrouchWalk 0.9.
- **Export settings that matter:** shape keys are exported dense (`export_try_sparse_sk=False`): Blender's sparse export writes a shape that leaves a primitive still as an accessor with no data, which older engine builds refused.
