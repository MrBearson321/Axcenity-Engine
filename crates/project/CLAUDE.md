# `project`

- Loads and saves project folders, including CSS source files. Open one file from the map in `docs/project-and-export.md`.
- `lib.rs` is the manifest, load and save; `scripts.rs`, `stylesheets.rs` and `templates.rs` hold those (re-exported from `lib.rs`). `ui_graphs.rs` compiles `ui/*.uigraph.json` to LocalScripts under their ScreenGuis. `world_file.rs` is `world.json`; `strings.rs` the string table, `strings.json`. `migrate.rs` upgrades an older manifest and keeps the previous files (`migrate_animation.rs` is the 2 → 3 step: one clip format, state machines). `terrain_files.rs` is Terrains' data folders (codecs in `terrain::files`). `packed.rs` packs a game; `package.rs` is asset packages (`.axpkg`, `docs/project/packages.md`). `versions.rs` keeps save history. `validate.rs` is the editor's asset check (`check_assets`); it must not write the project. `asset_fix.rs` plans its fixes (`plan_fix`) without writing; only the ignored list (`.axcenity/asset-check.json`) is written there.
- Keep serialization deterministic and report damaged files through the existing `Project::problems`/error paths. Bump `FORMAT_VERSION` only with a migration plan.
- When core properties or enums change, update both project parsing and writing, and keep the example-project tests passing.
