# `assets`

- Loads project asset files (glTF, FBX and OBJ models) into plain data, and copies imported models into a project. Paths: `docs/project/assets.md`. Meshes and maps: `docs/rendering/models.md`. Asset IDs and their `*.import.json` sidecars: `asset_id.rs`; references by ID (`ax://…`, resolved to a path before any load or cache lookup) and `branding://icon`/`banner` (`Assets::set_branding`): `references.rs` (`docs/editor/assets.md`). Cooked whole models: `model/cooked_model.rs`; a new field on `Model`, `Primitive`, `ModelMaterial` or `Rig` must be encoded there.
- No engine-crate dependencies; `scene` turns models into draw items and `physics` into hulls. Read files only through here, inside the project folder (`safe_path`). `Assets::fonts` reads the project's `.ttf`/`.otf` files once (`forget_fonts` rereads). `Assets::material` reads a `*.material.json` file and its bases (`material.rs`; format in `docs/rendering/models.md`). `Assets::data_table` reads a data table (`data_table.rs`; `docs/project/data-tables.md`). `Assets::rig_definitions` reads `assets/rigs/**/*.rig.json` bone maps once (`rig_definition.rs`; roles are `anim`'s; `docs/project/animation-files.md`). `Assets::reload` (`reload.rs`) swaps in a changed file and keeps the last good version when the new one fails (live reload, `docs/editor/scripts.md`).
- Loading must never panic on a bad file: `load_model` turns `gltf` and `ufbx` panics into `ModelError::Damaged`, and each failure is reported once (`Assets::take_errors`). FBX and OBJ are read from memory only (`load_external_files: false`; an OBJ's `mtllib` is read here and passed as `obj_mtl_data`); their textures are found by `fbx::texture_path`, inside the folder. Files are read with the lock released, through `Assets::load` (`loading.rs`, `docs/project/assets.md`); never read or decode under `lock()`.
- A `MeshId` can pick objects in its file (`file.fbx#A/B,C`, `model/objects.rs`); glTF and FBX must build object paths the same way, with `Siblings`.
- What a texture is for, by file name, and channel-packed layouts: `model/maps.rs` (`role_from_name`, `ModelMaterial::set_map`). A texture set groups those maps in one file: `texture_set.rs`; loose maps of one material are grouped into a folder with a set by `texture_pack.rs` (`texture_pack_name` in `model/maps.rs`).
- Levels of detail (`Primitive::lods`: a file's `_LOD1`/`_LOD2` objects, or simplified with `meshopt` at load, kept on disk by `model/lod_cache.rs`): `model/lod.rs`. `Posed` skins each primitive and level only when asked (`Posed::primitive`).
- Blend shapes (morph targets): `model/morph.rs` (`Model::morph_targets`, sparse `Primitive::morphs`; `docs/rendering/animation.md`). Skeletons, takes and posing: `model/rig.rs` (`Posed::joints` for the GPU, `Posed::primitive` skins on the CPU); `model/test_rig.rs` generates the rigged example FBX (`AXCENITY_WRITE_EXAMPLES=1` rewrites it). In FBX clusters, `Transform` is the inverse bind. glTF skins are read too (`gltf_rig` in `model.rs`; a skinned mesh ignores its node's transform).
