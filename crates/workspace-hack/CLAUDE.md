# `workspace-hack`

- Generated by cargo-hakari; no code. Every engine crate depends on it so shared libraries get the same features in any build. Why and how: `docs/development.md`.
- Don't edit between the `HAKARI SECTION` markers. After adding, removing or changing a dependency, run `cargo hakari generate` (and `cargo hakari manage-deps` for a new crate). CI is off, so check locally (docs/development.md).
- Settings, including crates left out (`final-excludes`), are in `.config/hakari.toml`.
