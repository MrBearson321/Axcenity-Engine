# `gameplay`

- Game systems moved out of `script` (roadmap L7), each a `script::GameSystem`: services, per-frame step and frame hooks. Debris (`debris.rs`); Health and Humanoids (`character_system.rs`, `health.rs`, `humanoid.rs`; hosts call `fire_landed`, `step_humanoids`, `step_health`, `share_nav_mesh`); Abilities and Effects (`ability_system.rs` is the system, `ability.rs`; hosts call `step_abilities` and `ability_bar`, `docs/scripting/api-abilities.md`); Tools (`tool_system.rs`, `tool.rs`; hosts call `step_tools`, `place_tools`, `player_inventory`, `docs/scripting/api-character.md`); dialogues and quests (`story.rs` is the system, `dialogue.rs`, `quest.rs`; hosts call `dialogue_view` and `quest_tracker`, `docs/scripting/api-dialogue.md`). `install` adds them all; every host's `ScriptRuntime` gets them (`sim::script_runtime`). Behaviour: `docs/architecture/game-systems.md`.
- Use only `script`'s public API (`axcenity_script::system`, the `ScriptRuntime` methods "for game systems", `LuaInstance`, `lent_world`); if a system needs more, make it public there on purpose.
- Systems step and hook in the order `install` adds them; `step` runs at Debris's old place in the script step (after content loading, before decals).
