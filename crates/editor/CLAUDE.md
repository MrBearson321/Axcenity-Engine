# `editor`

- eframe/egui editor. Big modules are a parent file plus a same-named folder: see "Where the big files split" in `docs/architecture/crates.md`. Open one file under `docs/editor/` (the list is in `docs/architecture.md`). Play mode: `docs/architecture/play-mode.md` (kept Play edits: `play/kept.rs`). Visual-debug overlays are editor-only (`viewport.rs`; View > Overlays). Welds, Attachments (stored relative to their part; the tools move them in world space via `constraints::localize`) and the Constraints overlay (joints too): `constraints.rs`. The Constraint tool (`app/constraint_tool.rs`; joints and movers, `constraints::takes_two_surfaces`) picks surfaces through `ViewportScene::constraint_pick` / `ViewportOutput::surface`, like a terrain brush takes the left button. Terrain Studio (including foliage): `docs/terrain.md`.
- `app.rs` runs the frame. Open and Play: `app/session.rs`. Selection, tools and undo: `app/edits.rs`. Insert, delete and reparent: `app/tree_ops.rs`. Menus and panels: `app/chrome.rs` (and `app/chrome/`). Console commands: `app/commands.rs`. Files, import and export: `app/files.rs` (and `app/files/`). Asset drops: `app/assets.rs` (a global asset is copied into the project first: `global_assets.rs`; route new uses through `EditorApp::use_global_asset`). Animation tab (follows the selected Animator; Animate is `EditorApp::animate`): `animation.rs` (and `animation/`); animated FBX import: `anim_import.rs`. UI Designer tab (artboard, rulers, anchors, palette, inspector, several selected; applied by `designer_actions` in `app/chrome/panes.rs` and `app/ui_selection.rs`): `ui_designer.rs` and `ui_designer/` (`docs/ui.md`). Engine rebuild and relaunch (debug builds from the source tree only): `rebuild.rs`, `relaunch.rs`, `app/engine.rs`; hot-patching with dx (dev `hot-patch` feature): `hot_patch.rs` (`docs/editor/scripts.md`). Profiler panel: `profiler.rs` (fed by `Session::cost` and the viewport). Asset Check panel: `asset_check.rs`, its scan and fixes in `app/asset_fixes.rs` (`project::check_assets`, `project::plan_fix`; editor-only). Input window (File > Input…, `input.json`): `app/input_settings.rs`; the ribbon's Controls menu: `app/controls_ui.rs`; Play's mouse and touch input from the viewport: `viewport/game_input.rs`. Tags panel: `tags.rs`, its actions `app/tags.rs`; Sequencer tab (Phase 51; timeline, dope sheet and curves reused from `animation/`, Scene view preview): `sequencer.rs`, its actions `app/sequencer.rs` (`docs/project/sequences.md`); Tests panel (Phase 53): `game_tests.rs` (runs on a thread through `axcenity_testing::Runner`), its actions `app/game_tests.rs`; spec tabs save as plain files in `write_tab` (`docs/project/game-tests.md`); Levels panel (Phase 48): `levels.rs`, its actions `app/levels.rs` (the open level is `OpenProject::level`; opening one goes through `Discard::OpenLevel`); attribute and tag edits go through `EditorApp::annotate` (`History::record_annotations`). Lua plugins (Phase 54; `docs/editor/plugins.md`): `plugins.rs` (state, Plugins panel), `app/plugins.rs` (calls, dock tabs, ribbon), their undo `history/edits.rs`. Model Studio tab (Phase 55; `docs/editor/model-studio.md`): `model_studio.rs` (own undo while hovered) and `model_studio/` (modeling tools and the adjust panel `tools.rs`, proportional editing and pivots `proportional.rs`, the Modifiers panel `modifiers.rs`, the UV menu and UV editor pane `uv_editor.rs`, Paint mode `paint.rs`, Sculpt mode `sculpt.rs`, drawn as chunk meshes through `view::Frame::sculpt`; retopology, Poly Build and Bake `retopo.rs`; Rig, Weights and Pose mode `rig.rs`, drawn through `View::use_model`), its open, save and bake `app/model_studio.rs`.
- Route edit-mode world changes through `EditorApp::change` so undo/history stays consistent; Play edits target the session world and are discarded on Stop. Clip, controller and prefab create, rename, duplicate and delete go through `History::record_asset` (a missing file is `None`). Prefab copies' Apply, Revert, Unpack and New variant: `app/prefabs.rs` and `prefab_menu.rs`, one `History::record_world_and_files` step each.
- Colours come from `theme::palette(ctx)` tokens and controls from `widgets.rs`; don't hardcode chrome colours. Panels must fit a 260-point column: use `responsive.rs` (`toolbar`, `form`, `split`) instead of fixed-width rows. Drawing tests need `theme::test_context()`. Don't call egui `Context`/`Response` methods inside an `input` closure; keep eframe, egui and render on compatible wgpu majors.
- Drawing tests save PNGs of what they draw when `AXCENITY_SNAPSHOTS` names a folder (`snapshot.rs`); look at them after UI changes.
- The generic node-graph editor is `node_graph.rs`; the UI Designer's Event Graph tab and Live Preview are `ui_designer/event_graph.rs`, graph documents, saving and their undo `app/ui_graphs.rs` (`docs/scripting/ui-graphs.md`). The Behavior Tree tab is `behavior_tree.rs` (documents, undo, drawing) and `app/behavior_trees.rs` (`docs/architecture/navigation.md`). The Data Table tab is `data_table.rs` and `app/data_tables.rs`; its edits go to `Assets` through `hand_over_tables` (`docs/project/data-tables.md`). The Material tab is `material_editor.rs` (its Graph view and Parameters `material_editor/graph.rs`) and `app/material_tab.rs`; its edits go to `Assets` through `hand_over_materials` (`docs/editor/assets.md`). Material graphs' nodes and their compiler to WGSL are `material_graph.rs` (editor-only: the player reads the WGSL; `docs/rendering/models.md`).
- egui fills only convex shapes: `block_editor.rs` fills blocks as convex pieces and outlines them as one path. The Graph view of block scripts is `block_editor/graph.rs` (`docs/scripting/graphs.md`).
