# `editor`

- eframe/egui editor. Big modules are a parent file plus a same-named folder: see "Where the big files split" in `docs/architecture/crates.md`. Open one file under `docs/editor/` (the list is in `docs/architecture.md`). Play mode: `docs/architecture/play-mode.md`. Visual-debug overlays are editor-only (`viewport.rs`; View > Overlays). Terrain Studio (including foliage): `docs/terrain.md`.
- `app.rs` runs the frame. Open and Play: `app/session.rs`. Selection, tools and undo: `app/edits.rs`. Insert, delete and reparent: `app/tree_ops.rs`. Menus and panels: `app/chrome.rs` (and `app/chrome/`). Console commands: `app/commands.rs`. Files, import and export: `app/files.rs` (and `app/files/`). Asset drops: `app/assets.rs` (a global asset is copied into the project first: `global_assets.rs`; route new uses through `EditorApp::use_global_asset`). Animation tab (follows the selected Animator; Animate is `EditorApp::animate`): `animation.rs` (and `animation/`); animated FBX import: `anim_import.rs`. UI Designer tab (artboard, palette, hierarchy; applied by `designer_actions` in `app/chrome/panes.rs`): `ui_designer.rs` (`docs/ui.md`). Profiler panel: `profiler.rs` (fed by `Session::cost` and the viewport). Asset Check panel: `asset_check.rs` (`project::check_assets`; editor-only).
- Route edit-mode world changes through `EditorApp::change` so undo/history stays consistent; Play edits target the session world and are discarded on Stop. Clip, controller and prefab create, rename, duplicate and delete go through `History::record_asset` (a missing file is `None`).
- Colours come from `theme::palette(ctx)` tokens and controls from `widgets.rs`; don't hardcode chrome colours. Panels must fit a 260-point column: use `responsive.rs` (`toolbar`, `form`, `split`) instead of fixed-width rows. Drawing tests need `theme::test_context()`. Don't call egui `Context`/`Response` methods inside an `input` closure; keep eframe, egui and render on compatible wgpu majors.
- Drawing tests save PNGs of what they draw when `AXCENITY_SNAPSHOTS` names a folder (`snapshot.rs`); look at them after UI changes.
- egui fills only convex shapes: `block_editor.rs` fills blocks as convex pieces and outlines them as one path. The Graph view of block scripts is `block_editor/graph.rs` (`docs/scripting/graphs.md`).
