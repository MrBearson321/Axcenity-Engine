# `ui`

- Turns ScreenGui, Frame, TextLabel, TextButton, ImageLabel, TextBox, PageLayout, Table, ScrollingFrame, the widgets and BillboardGui into screen-space draw data, applying parsed CSS stylesheets.
- Uses Taffy for absolute and flex layout; `UDim2` combines parent-relative scale and pixel offsets. `ScaleMode` Fit and Scale scale from the design size (`fit_transform`); `layout_artboard` lays one ScreenGui out for the UI Designer.
- `style.rs` parses selectors, specificity, variables and warnings; its `StyleCache` (M14) keeps each element's matched styles for one frame's layout passes, so resolve styles through `resolve_styles`/`shared_styles` with the pass's `PseudoClasses`, never by walking ancestors yourself. `lib.rs` lays out with taffy, `paint.rs` makes draw items (`paint_box`: shadows, background, borders), `css.rs` reads CSS values and `rich.rs` reads `RichText` tags into `UiText::spans`. `accessibility.rs`: the game UI settings' text scale and higher contrast, applied to draw items after layout (reduced motion is in `transition.rs`). `loading.rs`: `LoadingGui`, the project's ScreenGui loading screen; hosts pass `on_top` in `UiInput`. Keep `render` free of Instances.
- Siblings are laid out in tree order and drawn (and hit) in `z_order`; `UiElement::clip` and each draw item's `clip` come from `overflow` and ScrollingFrames. `scroll.rs`: a ScrollingFrame's canvas (`UiScroll`) and bars.
- `turn.rs`: `Rotation` turns an element's subtree after it's laid out (`UiTurn` on each `UiElement`; hit tests turn the pointer back). `ScreenInsets` with `DeviceSafeInsets` lays a ScreenGui out inside `ArtboardView::safe_insets` (`gui_area`).
- `interact.rs`: hosts keep one `UiInteraction` for hover, press, tooltips, the cursor, scrolling and widget values (`UiScrolled`) and `UiEvent`s; `transition.rs` eases styles (`transition`) by resolving them through it. `layout_artboard_in_state` shows one element in a `UiState`. `interact/focus.rs`: keyboard and controller focus (`NavKey`, `navigate`, `takes`, `:focus`, the default ring); `gamepad.rs` reads controllers with `gilrs` as `InputEvent`s; `nav_key` and `PadNavigation` turn the input map's UI actions into `NavKey`s.
- `widget.rs`: Slider, Toggle, Dropdown and ProgressBar parts (pseudo-elements, defaults written as CSS), a Slider's `UiTrack` and an open Dropdown's list, which `UiInteraction` draws last. `prompt.rs`: the ProximityPrompt's box, `::key` cap and `::ring` (`prompt_items`, drawn over the UI from the host's prompt views). `hotbar.rs`: the default hotbar (`hotbar_items`, an Inventory's Tools; `Tool:checked` is the one in hand). `ability_bar.rs` (Phase 76): the ability bar (`ability_bar_items`, from `core::ability::AbilitySlot`s, with cooldown sweeps). `dialogue_box.rs` (Phase 77): the dialogue box and quest tracker, styled through `style::Widget` type names (`resolve_widget_styles`). `leaderboard.rs`: the default leaderboard (`leaderboard_items`, each Player's `leaderstats`). `chat.rs`: the default chat window (`chat_items`, styled by `TextChatService` rules).
