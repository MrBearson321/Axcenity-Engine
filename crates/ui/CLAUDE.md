# `ui`

- Turns ScreenGui, Frame, TextLabel, TextButton, ImageLabel, TextBox, PageLayout, Table, ScrollingFrame, the widgets and BillboardGui into screen-space draw data, applying parsed CSS stylesheets.
- Uses Taffy for absolute and flex layout; `UDim2` combines parent-relative scale and pixel offsets. `ScaleMode` Fit and Scale scale from the design size (`fit_transform`); `layout_artboard` lays one ScreenGui out for the UI Designer.
- `style.rs` parses selectors, specificity, variables and warnings. `lib.rs` lays out with taffy, `paint.rs` makes draw items (`paint_box`: shadows, background, borders), `css.rs` reads CSS values and `rich.rs` reads `RichText` tags into `UiText::spans`. `loading.rs`: `LoadingGui`, the project's ScreenGui loading screen; hosts pass `on_top` in `UiInput`. Keep `render` free of Instances.
- Siblings are laid out in tree order and drawn (and hit) in `z_order`; `UiElement::clip` and each draw item's `clip` come from `overflow` and ScrollingFrames. `scroll.rs`: a ScrollingFrame's canvas (`UiScroll`) and bars.
- `turn.rs`: `Rotation` turns an element's subtree after it's laid out (`UiTurn` on each `UiElement`; hit tests turn the pointer back). `ScreenInsets` with `DeviceSafeInsets` lays a ScreenGui out inside `ArtboardView::safe_insets` (`gui_area`).
- `interact.rs`: hosts keep one `UiInteraction` for hover, press, tooltips, the cursor, scrolling and widget values (`UiScrolled`) and `UiEvent`s; `transition.rs` eases styles (`transition`) by resolving them through it. `layout_artboard_in_state` shows one element in a `UiState`. `interact/focus.rs`: keyboard and controller focus (`NavKey`, `navigate`, `takes`, `:focus`, the default ring); `gamepad.rs` reads controllers with `gilrs`. Hosts map their own keys (`nav_key` in the player and editor).
- `widget.rs`: Slider, Toggle, Dropdown and ProgressBar parts (pseudo-elements, defaults written as CSS), a Slider's `UiTrack` and an open Dropdown's list, which `UiInteraction` draws last.
