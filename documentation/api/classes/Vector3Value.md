# Vector3Value

```luau
Instance.new("Vector3Value")
```

Holds one Vector3 in Value. Its `Changed` fires with the new value.

It also has every member of [Instance](Instance.md).

### Properties

#### Value

```luau
Vector3Value.Value: Vector3
```

The Vector3 it holds. Zero by default.
