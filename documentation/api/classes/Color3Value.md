# Color3Value

```luau
Instance.new("Color3Value")
```

Holds one Color3 in Value. Its `Changed` fires with the new value.

It also has every member of [Instance](Instance.md).

### Properties

#### Value

```luau
Color3Value.Value: Color3
```

The Color3 it holds. Black by default.
